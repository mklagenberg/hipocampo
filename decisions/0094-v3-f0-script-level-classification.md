# 0094 — V3 F0 script-level classification

**Status:** Accepted for the unreleased V3 candidate

## Context

F0 needs a usable classification of deterministic, cognitive, human and hybrid
behavior without pretending that semantic work is mechanical proof.

## Decision

Classify relevant scripts as a whole in this wave. Record each script's proof
boundary and keep operation-level classification as a future evolution.

## Rationale

This reduces initial complexity while preserving explicit proof limits and a
future path to finer-grained classification.

## Consequences

The first inventory is simpler, but hybrid scripts must document their limits.
The class never authorizes a claim beyond the evidence produced.

## Discarded alternatives

- Operation-level classification was deferred to a future evolution.
- Binary classification was rejected because it loses human and hybrid work.

## Validation plan

Validate complete inventory coverage and exercise deterministic, hybrid and
semantic fixture classes.
