# Change Set 0095 — V3 F0 phase verification matrix

## Intent

Make verification obligations proportional to lifecycle phase.

## Scope

Add the execution, review, publication, migration and retraction matrix and
fixtures for complete, partial and blocked proof.

## Acceptance criteria

- all five phases are represented;
- required checks, blocking conditions and evidence are explicit;
- cross-phase operations cannot silently skip an applicable gate.
