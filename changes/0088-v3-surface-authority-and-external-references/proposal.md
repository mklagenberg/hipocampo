# Change Set 0088 — V3 surface authority, offline behavior and external references

## Intent

Implement D5.5 and D5.6 as a single candidate boundary for source discovery,
offline behavior and external-reference labelling.

## Scope

Document the authority crosswalk, fail-closed offline behavior and external
reference boundary; add integrated fixtures and deterministic validation.

## Acceptance criteria

- canonical SPEC and accepted decisions remain primary;
- skill is procedural, not a substitute source;
- offline normative uncertainty is disclosed and blocked;
- proven mechanical work may continue with limits recorded;
- external references are explicitly labelled and not adopted implicitly;
- cross-surface validation passes after correction.

## Compatibility and recovery

The candidate is unreleased. Existing v2 instances and the published skill
package are not silently upgraded.
