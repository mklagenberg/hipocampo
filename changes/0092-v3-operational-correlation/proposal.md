# Change Set 0092 — V3 operational correlation

## Intent

Implement X6.4 correlation, approval and delegation without secrets or a
central content graph.

## Scope

Add structured correlation primitives, contract documentation and inaccessible
frontier fixtures.

## Acceptance criteria

- IDs, fingerprints and evidence references are present;
- actor roles remain distinct;
- inaccessible frontiers are disclosed;
- correlation does not alter authority or copy content.
