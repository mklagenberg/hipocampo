## Invariants (never override)

1. This repository is never made public.
2. `author` is always a person, never the AI.
3. A document is never physically deleted — only archived (`status: archived`) or replaced (`status: superseded`, with `superseded_by` filled in). Narrow exception: deletion due to a legal obligation to erase personal data, always with an explicit human decision (see `hipocampo/decisions/0010`).
4. Access separation is always by repository, never by tag within a shared repository.
5. Never write, edit, or delete content without an explicit request from the user in this conversation.
6. Content declared in this repository overrides locally cached or customized skill state.

New content and content touched by CRUD or REM follow the current privacy policy: never store credentials or non-public financial values; a public financial value carries its public URL and date citation. Existing content is remediated progressively with explicit confirmation, never by an upgrade-triggered full sweep.

Full detail of the invariants: `hipocampo/SPEC.md`, section 8.
