# Pending access and provisional fallback

Diagnose pending invitation, insufficient permission, incorrect address,
connector unavailable and tool unavailable separately. Prefer the same-entity
destination; use the personal anchor only when its contract authorizes the
operation. If no authorized destination exists, block.

The provisional workaround accepted for MRL-0002 does not automatically copy
raw sensitive material, declassify or promote incomplete information, or move
content between entities. A minimal pending record is allowed only when
authorized and non-sensitive, with explicit confirmation. This policy must be
revisited in MRL-0004, when vault hierarchy and confidentiality policy are
defined.
