## Release notes

### Hipocampo v3.0.0 — Governed knowledge and canonical operations

This major version defines governed Records, Chunks, Collections and Artifacts,
explicit entity/vault responsibility, independent knowledge states and
progressive disclosure. Canonical CRUD provides the governed persistence
boundary; uncertainty, privacy and provenance remain explicit.

The portable skill is version 2.0.0, compatible with methodology ^3.0.0 and
bound to an exact file lock. The new-vault scaffold prepares V3 proposals;
existing vaults require separately reviewed mappings and migration.
The V2 specification, guides and prior skill remain preserved for reference.

### Validation and demonstrated scope

Local structural, contract, package and differential checks passed, together
with 27 adversarial release regressions and the integrated V3 engine suite.
The exact stable skill received primary AI review and a separate challenge.
These assessments do not replace the final human decision or publication proof.

The demonstrated operational environment is bounded local Python/Git.
Three accepted pilot migrations passed fresh reload in the preceding local
experiment; 335 reviewed knowledge items remain held. Pilot evidence used the
experimental rc.1 package. Other host adapters require their own capability and
authorization verification. No global installation or universal host support
is claimed. Actual restoration was not performed.

### Migration and recovery

This is an incompatible methodology upgrade. A V2 instance requires governed,
per-vault preparation and accepted item mappings before V3 writes. Preserve
source/context fingerprints, privacy boundaries and cumulative Collections;
write only through canonical CRUD. Reconcile partial effects before retrying.
Recovery is ticket-bound and requires the applicable approval.

See `MIGRATIONS.md`, `UPGRADE.md` and `docs/v3-migration-execution.md` in the
verified release source. Publishing this methodology does not automatically
upgrade installed skills or accept migration proposals.
