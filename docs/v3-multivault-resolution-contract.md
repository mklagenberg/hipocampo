# V3 multivault resolution

X4.2 represents relationships between vaults as typed, scoped edges. Delivery,
reference, split, copy and hereditary succession are different relations.

Graph traversal is deterministic, but it does not grant access, select semantic
truth or merge entities. Cycles and authority collisions are diagnostics.
Unavailable vaults create partial frontiers. Their content and identity are
not included in the visible result.
